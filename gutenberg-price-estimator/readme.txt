A block that lets visitors estimate a subscription price from your packages, billing model, branches and add-ons.

== Description ==

Add the "Price Estimator" block to any page. Set your packages, add-ons and currency in the block sidebar; visitors choose a package, how they pay, the number of branches and add-ons, and see an estimate. Without JavaScript, visitors see a plain list of packages.

== Installation ==

1. Upload the plugin zip under Plugins > Add New > Upload Plugin, then activate it.
2. Edit a page, add the "Price Estimator" block (Widgets category) and configure it in the sidebar.
